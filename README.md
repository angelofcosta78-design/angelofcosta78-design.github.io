# angelofcosta78-design.github.io

Site do Prof. Angelo Costa — portal de Engenharia Mecânica.

Arquivos incluídos:

- index.html — página principal estática
- styles.css — estilos

Como manter:

- Edite `index.html` e `styles.css` localmente e faça push para a branch `main`.
- Para conteúdo dinâmico e organização de materiais recomendo migrar para um gerador de site estático (Hugo ou Jekyll).
